# WS- · 文思泽作品网站

网站入口是 `dist/index.html`。HTML、CSS、交互脚本与 WebGL 布料模拟均在这一个文件中，无框架、无构建步骤；作品视频与播放封面保存在 `dist/media/`。

双击文件即可浏览；也可以在 dist 目录启动静态服务器。午后教室插画已内嵌在 HTML 中，布料上的“文思泽作品网站”文字由网页绘制。在线字体需要网络连接。

## 内容

- 首屏：可拖拽插画布料、“文思泽作品网站”标题与个人定位。
- 作品与实践：TVC广告（AIGC）、C4D.AE综合展示、电商视频（AI与C4D动画）、AI微电影四个分区，支持分类筛选与详情弹窗。TVC 分区收录《TVC.mp4》；C4D.AE综合展示收录《作品.mp4》；电商视频上下展示《C4D OC与AE后期综合运用》（C4D动画）与《SKG按摩仪》（AI生成）。播放器支持播放、暂停、进度拖动与全屏；同一时间只播放一支，关闭详情后自动暂停。AI微电影为创作方向展示。
- 创作方式：从创意、生成到动态与交付的四步流程。
- 关于我：实习、教育、工具与简历速览。
- 联系：邮件、电话与邮箱复制。

内容依据用户提供的《直聘简历-文思泽.pdf》整理。未将简历文件上传为网站资源。未展示期望薪资、性别与年龄。

TVC广告（AIGC）、电商视频与AI微电影卡片使用已标注的概念封面。C4D.AE综合展示封面及播放器封面截取自对应视频；三处视频分区共收录用户提供的四支真实作品。新增的 TVC 与 SKG 视频使用适合网页加载的 720p H.264/AAC 播放版本，保留完整时长和原始视频文件。

如需复制、上传或部署网页，请保留完整的 `dist/` 文件夹及 `media/` 子目录，视频使用相对路径引用。

仓库保留网页源码与说明。临时预览、简历原文件、发布账户配置不纳入版本控制。
